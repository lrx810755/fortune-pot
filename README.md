A fortune written for a houseplant: **"Soon a sunbeam will find your leaves, and you will stretch toward it like a small green victory. Grow tall, little one."**

## Run

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
